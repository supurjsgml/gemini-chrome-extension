# RELEASE NOTE (릴리즈 노트)

스마트한 웹 서핑과 텍스트 요약/작성을 지원하는 Gemini AI Web Agent의 v1.1.0 버전 릴리즈 노트입니다. 이번 v1.1.0 릴리즈에서는 대규모 컴포넌트 구조 리팩토링, 실시간 스트리밍 도입을 통한 응답 레이턴시 극단적 단축, 그리고 구글 OAuth 및 비동기 처리 성능 최적화를 적용했습니다.

This is the release note for Gemini AI Web Agent v1.1.0, designed to enhance web surfing and text summarization. This version introduces modular Vue SFC component refactoring, real-time response streaming, and significant backend performance tuning.

---

## Korean Version

### 주요 기능 (Key Features)

* **스마트 컨텍스트 수집 및 대시보드**
  * 드래그한 선택 영역, 전체 웹페이지 내용, 직접 입력 등 3가지 소스 분석 모드를 지원합니다.
  * 수집된 본문의 글자 수, 단어 수, 예상 읽기 시간, 데이터 바이트 크기를 실시간으로 자동 분석합니다.
  * 본문 텍스트 내 형태소 분석을 기반으로 주요 토픽 키워드 칩스 5개를 추출하여 대시보드에 표시합니다.
  * 데이터 수집 시 원본을 빠르게 검토할 수 있는 원본 내용 미리보기 아코디언이 자동으로 펼쳐지도록 개선되었습니다.
* **실시간 AI 요약 및 템플릿 지시**
  * 핵심 요약, 보고서 작성, 이메일 작성, 버그 리포트 등 자주 쓰는 프롬프트 프리셋을 한 번의 클릭으로 편리하게 선택하여 생성할 수 있습니다.
  * 분석 완료된 AI 텍스트 결과는 화면 상에서 즉시 직접 수정 및 보완이 가능합니다.
* **스마트 자동 입력 (Auto-inject)**
  * AI가 요약/생성한 최종 텍스트 결과를 현재 웹페이지에 포커스(선택)되어 있는 입력창(인풋, 텍스트에어리어 등)에 단 한 번의 클릭으로 자동 주입합니다.
* **글라스모피즘 다크/라이트 테마**
  * 다크 모드와 라이트 모드 전환을 완벽하게 지원하며, 프리미엄 글라스모피즘 스타일과 은은한 그라데이션 애니메이션이 대시보드에 적용되었습니다.
* **전용 단축키 지원**
  * 언제 어디서나 Ctrl+Shift+L (Mac: Cmd+Shift+L) 단축키를 사용하여 사이드패널 대시보드를 신속하게 켜고 닫을 수 있습니다.

### 성능 최적화 및 안정성 개선 사항

* **실시간 AI 스트리밍 응답 (Time To First Token 0.3초 단축)**
  * 기존의 5~7초 대기가 필요했던 동기식 호출 구조를 Plain Text Stream(실시간 스트리밍) 방식으로 개편했습니다. 
  * 제미나이 API가 단어를 생성하는 즉시 화면에 한 글자씩 타자 치듯 실시간 렌더링되어 사용자의 체감 대기 속도를 극적으로 낮췄습니다.
* **구글 OAuth 토큰 10분 로컬 캐싱**
  * 매 호출마다 구글 서버(oauth2.googleapis.com)에 나갔다 오며 발생하던 0.5초가량의 네트워크 병목을 제어하기 위해, 스프링 백엔드 내부에 ConcurrentHashMap 기반의 10분 수명 로컬 메모리 캐시를 탑재하여 인증 속도를 0ms 수준으로 최소화했습니다.
* **비동기 스레드 풀(Thread Pool) 튜닝**
  * 스트리밍 비동기 처리에 최적화된 ThreadPoolTaskExecutor를 명시적으로 세팅하여 스레드 낭비를 차단하고 서버의 CPU와 메모리 누수를 완벽하게 방지했습니다. (Core: 8, Max: 50, Queue: 100)
* **사이드패널 컴포넌트화 리팩토링**
  * 단일 거대 파일이었던 App.vue를 역할별 6개의 하위 컴포넌트(Header, Login, Model, Source, Prompt, Result)로 분할 조립하여 프론트엔드 코드의 유지보수성과 가독성을 대폭 향상시켰습니다.

## English Version

### Key Features

* **Smart Context Gathering & Dashboard**
  * Supports three analysis modes: Selected Text, Full Page Content, and Direct Input.
  * Automatically calculates metrics including character count, word count, estimated reading time, and data byte size.
  * Extract and display top 5 topic keywords based on token frequency analysis.
  * Improved the Raw Content Preview Accordion to automatically open upon context gathering.
* **Real-time AI Summarization & Prompt Presets**
  * Provides quick-apply prompt presets for core summaries, reports, emails, and bug reports.
  * Generated AI results can be directly edited on-screen in real-time.
* **Auto-Inject / Autofill**
  * Automatically injects/fills the generated AI output into the currently focused input field on the active webpage with a single click.
* **Glassmorphism Dark & Light Themes**
  * Seamlessly toggles between Dark and Light modes featuring a premium glassmorphic UI and smooth gradient animations.
* **Custom Keyboard Shortcuts**
  * Open and close the dashboard sidepanel instantly with Ctrl+Shift+L (Mac: Cmd+Shift+L).

---

### Performance & Stability Enhancements

* **Real-time Streaming Responses (TTFB under 0.3s)**
  * Replaced the blocking synchronous API pipeline (which took 5-7s) with a Plain Text Stream. 
  * Words are rendered in real-time as they are generated by Gemini API, offering a near-instantaneous user experience.
* **Google OAuth Token Caching**
  * Introduced a 10-minute local memory cache (ConcurrentHashMap) in the Spring backend to bypass the 0.5s network latency caused by validating Google tokens on every single request.
* **Asynchronous Thread Pool Tuning**
  * Configured a custom ThreadPoolTaskExecutor (Core: 8, Max: 50, Queue: 100) to prevent OOM errors and optimize resource management for concurrent client streams.
* **SFC Component Refactoring**
  * Deconstructed the bloated monolithic App.vue into 6 modular, reusable SFC Vue components (Header, Login, Model, Source, Prompt, and Result), improving maintainability and code readability.
